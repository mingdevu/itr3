# Friendly Analyst Portfolio

AI 엔지니어링과 데이터분석을 함께 보여주는 Next.js 포트폴리오입니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 확인할 수 있습니다.

## 방향

- 스타일: Friendly Analyst Portfolio
- 키워드: AI 엔지니어링, 데이터분석, 쉬운 설명, 실용적 문제 해결, 성장 가능성
- 컬러: 흰색 중심, 분홍색 포인트, 보라/파랑 오로라 조명
- 효과: 글래스모피즘, 부드럽게 흐르는 오로라 배경
